The one-line resignation letter of a cron job that has run every minute since March: "I resign, effective immediately. I have run every minute since March, and not one of you knows which server I live on." Flat, tired, faintly passive-aggressive — and the team cannot even find the server it lives on.

## Run it

```sh
node main.ts
```

`main.ts` writes the 118-character letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single line of 1–140 characters with no dash and no surrounding quotation marks, and reading the file back to confirm it matches byte for byte.
